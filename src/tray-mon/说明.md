# TrayMon — 任务栏实时性能监控（使用说明）

> 版本 1.0.0 ｜ Windows 7 SP1 及以上（32 / 64 位）｜ 纯标准库，绿色免安装
> 形态参考 TrafficMonitor：把 CPU、内存、网速、磁盘占用贴在任务栏右下角

---

## 1. 怎么跑起来

**最省事**：解压后双击 `启动托盘监控.bat`（不会弹黑框）。

用它自带的 `python.exe` 直接跑也行：

```cmd
python.exe tray_mon.py
```

第一次运行后，任务栏右下角（系统时钟左边、托盘箭头左边）就会出现一条监控条：

```
↓ 15.3 KB/s   ↑ 26.2 KB/s   CPU 55%   MEM 80%   DSK 52%
```

同时通知区域多了一个显示 CPU 百分比的图标（例：`55`，底部一条橙色负载条）。

**想开机自动启动**：右键监控条 → 勾选「开机自动启动」。它写的是当前用户的
`HKCU\...\Run`，不需要管理员权限。

> ⚠️ 启用开机自启后**不要移动/改名这个文件夹**——注册表里记的是绝对路径，挪了就失效，
> 右键取消再重新勾选一次即可。

---

## 2. 右键菜单

监控条和托盘图标上右键都能呼出同一份菜单：

| 菜单项 | 说明 |
|---|---|
| 显示 网络速率 / CPU 占用 / 内存占用 / 磁盘占用 | 勾选状态即是否显示，至少保留一项 |
| 刷新间隔 1 / 2 / 5 秒 | 默认 1 秒 |
| 深色主题 | 勾掉即浅色主题（浅灰底 + 深色字） |
| 停靠在任务栏 | 勾掉变成桌面悬浮窗，可**按住拖动**，位置会记住 |
| 开机自动启动 | 写/删 `HKCU` 的 Run 项 |
| 退出 | 干净退出，顺便保存配置 |

监控条上**左键单击**也是打开菜单（避免误点）。

## 3. 命令行参数

```cmd
python.exe tray_mon.py --probe                  :: 只采样一次并打印 JSON，不显示界面
python.exe tray_mon.py --items cpu,mem          :: 只看 CPU 和内存
python.exe tray_mon.py --interval 2             :: 2 秒刷新
python.exe tray_mon.py --theme light            :: 浅色
python.exe tray_mon.py --no-dock                :: 悬浮窗模式（默认右上角）
python.exe tray_mon.py --font-size 13           :: 字号像素（默认按 DPI 自动 12px@96dpi）
python.exe tray_mon.py --font-face "微软雅黑"    :: 字体
python.exe tray_mon.py --disk D                 :: 磁盘占用看 D 盘
python.exe tray_mon.py --no-tray                :: 不要通知区图标，只留任务栏条
python.exe tray_mon.py --exit-after 5           :: 跑 5 秒自动退出（自测用）
python.exe tray_mon.py --dump-icon icon.bmp     :: 导出托盘图标位图，核对绘制
python.exe tray_mon.py --version
```

配置保存在同目录 `tray_mon.json`，命令行参数会覆盖配置。

## 4. 数据是怎么来的

| 指标 | 系统 API | 说明 |
|---|---|---|
| CPU | `GetSystemTimes` | 差值法算总占用率，与任务管理器同一来源 |
| 内存 | `GlobalMemoryStatusEx` | 物理内存占用百分比 |
| 网速 | `GetIfTable` | 汇总所有“已连接”网卡的收发包计数，跳过回环/隧道 |
| 磁盘 | `GetDiskFreeSpaceEx` | 选定盘符的使用率，默认 C: |

两个已处理的坑（自己改代码时会遇到）：

1. **`GetIfTable` 是按 IP 地址出行，不是按网卡**。同一张网卡有多个 IP 时会重复出现好几行、
   计数完全一样，直接求和会把网速放大 2~4 倍。程序按 MAC 地址去重。
2. **`dwOperStatus` 用的是内部状态枚举**（4=Connected、5=Operational），
   不是 `IF_OPER_STATUS` 的 1=Up；写成 `==1` 会一行都匹配不到，网速永远 0。

另外 32 位计数器到 4 GiB 会回绕，已按取模处理。

## 5. 资源占用

- 界面全部 GDI 自绘 + 双缓冲，没有定时器堆叠、没有重复创建 GDI 对象
- 内存常驻约 12~18 MB（其中 6 MB 是 Python 运行时本身）
- CPU 占用通常 < 0.2%（1 秒采样一次，每次只调 4 个系统 API）

## 6. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 双击 bat 没反应 | 缺 KB2999226（Universal C Runtime）或 VC++ 2015-2019 运行库，装完再试 |
| 没看到监控条 | 任务栏可能被设置成竖排或自动隐藏；右键托盘图标 → 勾掉「停靠在任务栏」改用悬浮窗 |
| 网速一直 0 | 网卡处于断开/休眠；或你的虚拟网卡被判定为隧道。用 `诊断.bat` 看真实计数 |
| 托盘图标不显示 | Win7 默认会把新图标塞进「隐藏图标」区，点小三角展开，或拖到可见区 |
| 图标背景是深色方块，跟浅色任务栏不搭 | 图标是深底白字的固定样式，与深色任务栏更协调；浅色任务栏下可 `--no-tray` 只用任务栏条 |
| 改了字号后字被裁 | 面板宽度按文字量算，不裁剪；若系统 DPI 非 100%，建议让 `--font-size` 留空自动适配 |
| 退出后配置没保存 | 必须从菜单「退出」（会存盘）；直接杀进程不会保存 |

## 7. 文件清单

| 文件 | 作用 |
|---|---|
| `tray_mon.py` | 主程序（单文件，纯 ctypes，无第三方依赖） |
| `python.exe` / `pythonw.exe` | 内置 32 位 Python 3.7.9 免安装运行时 |
| `启动托盘监控.bat` | 双击启动（用 pythonw，无黑框） |
| `诊断.bat` | 采样一次 + 打印窗口矩形，排错用 |
| `tray_mon.json` | 配置（首次运行后自动生成） |
